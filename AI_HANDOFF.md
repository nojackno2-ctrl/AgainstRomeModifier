- User-reported editor expectation/regression audit (2026-07-14): the user reports that 3D cannot be entered and that `新建地圖` opens an endless-map copy instead of a genuinely blank authored map. Static diagnosis confirms the second behavior is intentional in current code but mismatched with the player-facing label: `MapSelectionForm.CreateMap` calls `SelectNewMapTemplate`, which always selects the first original `ENDL_*`, then `EndlessMapCloner` recursively copies every source file. No blank-map generator exists.
