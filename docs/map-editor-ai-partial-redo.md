# AI 局部重做與保護區

2026-10-08 Codex。

在多 AI 製圖對話框勾選需要重新生成的地形、水系、材質角色。未勾選角色不送出推論，依地形→水系→材質順序逐一執行；OllamaMapPlanner 的 process-wide semaphore 仍限制一次一個推論。

範圍輸入 `X,Y,寬,高`，例如 `8,8,40,40`。鎖定區每行一個相同格式的矩形，例如 `20,20,8,8`。座標為全圖格座標，矩形右、下邊界不包含在 tile 範圍內；區域必須位於 64×64 地圖內。

「允許修改通行」預設關閉。即使模型違反描述生成 blocked/passable，碰撞層仍保持原值。開啟此選項且選取地形角色後才套用通行變更，並遵守範圍與鎖定遮罩。

高度與材質共用邊界可能影響相鄰格，因此凡是接觸保護格的頂點／角點均保留。材質使用原生角點與 transition 烘焙，無法表示的材質區會拒絕；受保護筆畫不允許向外 auto-bridge。保護格的材質字串與角點不會被旁邊烘焙改寫。

預覽在獨立高度、碰撞與材質快照執行相同套用器，範圍外與鎖定區顯示灰暗。候選結果交給 MapDiagnostics，問題清單包含既有問題；實際 Apply 後刷新地圖檢查分頁。修改角色、模型、描述、範圍、鎖定區或通行選項會使舊方案失效，需重新生成後才能 Apply。

鎖定區只保護這次 AI 操作，關閉對話框後不保存，也不限制手動畫筆。高度與碰撞合為一筆復原，材質另為一筆復原；使用既有儲存交易。AI 不修改放置物件、森林或事件。

驗證包含角色子集、保護格與共用邊界、材質角點與相鄰烘焙、undo/redo、舊方案失效，以及明確啟用的本機推論→預覽→Apply→儲存→新表單重開。遊戲內效果由示範地圖驗收另行確認。
