# 地圖編輯器開發順序

2026-10-07，Codex；依使用者指示重新整理順序，整理後按下列階段續作。

## 範圍與依賴

- 主目標仍是完成地圖編輯器，匯出的地圖外觀與行為符合原版格式要求。
- 「本地 AI」原指開發時呼叫的子代理。產品內的 AI 製圖是先前誤解後新增的功能，使用者現在明確要求保留並完善。兩者的模型選擇與工作流程分開處理。
- 以 `map-editor-spec.md`、`map-editor-3d-view-spec.md` 為需求來源，`map-editor-acceptance.md` 記錄證據。舊規格中的路徑、階段與已更改的啟動架構須依當前程式碼核對，不能把舊清單照抄為新工作。
- 依序完成下列階段；發現前置階段的正確性缺陷時先修缺陷，不因 AI 或 UI 功能較容易展示而跳過。

## 1. 收斂需求與驗收缺口

逐項核對原規格、已實作能力與驗證證據，分清楚「已實作」「合成資料已驗證」「遊戲內已驗證」。確認空白地圖、部族與多人等項目的正式支援邊界，不把尚未證實的行為列成可用功能。

完成條件：每個必要功能都對應實作位置、驗收方式與目前缺口；開發 AI 與產品 AI 的用途不再混淆。

## 2. 完成可靠的手動編輯核心

先核對建立／複製／開啟／儲存／重新載入流程，再完成高度、通行、原版材質、環境與文字屬性；確保 undo/redo、dirty、成功儲存基準與失敗重試一致。已有測試通過的路徑不重寫，優先補真正缺少的案例與修正。

完成條件：同一張合成地圖能完成連續編輯、復原、儲存失敗後重試與重新開啟；原版資料與未知欄位被保留，沒有半套寫入。

## 3. 完成物件、部隊與事件的整合

核對建築／人物／部隊／自然物件的放置、編輯、複製、刪除；保留永久目標身份。補部族、隊伍槽位與區域／勝敗事件的跨功能案例，確認腳本生成、DATA binding 與存檔交易一致。多人同步屬遊戲內驗收，不能由槽位測試推定支援。

完成條件：場景、放置與事件共同儲存後可重新載入；無效目標、位置及隊伍在寫入前拒絕；部族／隊伍覆蓋與未支援範圍有明確紀錄。

## 4. 把 AI 製圖做成完整產品功能

在已驗證的編輯核心上完善以下流程，不建立另一套地圖寫入方法：

- 服務連線、可用模型選擇與明確的生成進度。
- 從目前地圖狀態產生可檢視的預覽，預覽不改動資料／歷史／檔案；顯示預計變更與被拒絕區域。
- 生成、取消、失敗／部分成功、重試與套用有一致狀態；舊方案不能誤套用。
- 套用後可復原並透過正常儲存交易寫檔；實際 Ollama 呼叫驗證與取消／錯誤測試分開記錄。
- 明確說明 AI 處理的地形／水系／材質範圍，以及尚未自動處理的物件、資源與遊戲規則。

完成條件：真實生成 → 預覽 → 套用 → 復原／重做 → 儲存 → 重新載入的完整流程有證據；生成成功不能取代可玩性驗收。

## 5. 完成顯示與操作驗收

核對真正 OpenGL 渲染、2D/3D 切換、選取與筆刷位置、資源缺失／context 失敗診斷；再檢查高 DPI、中英文、最小視窗尺寸與長訊息。96 DPI 預覽已完成，但不是 OpenGL 或高 DPI 證據。

完成條件：可用畫面與編輯資料一致，fallback 可操作且有實際原因，必要控制項不遮擋。

## 6. 遊戲內驗收與交付

驗證匯出地圖載入、地形與原生材質、碰撞、物件／部隊、區域事件／勝敗、遊戲存讀檔；再驗證正式支援的部族與多人範圍，以及 AI 方案的通路與可玩性。完成後才進入發行建置與文件核對。

完成條件：必要項目有遊戲內證據，Release build/test 與交付文件一致。`AGENTS.md` 已授權受限實機驗收：只能修改自製測試地圖，先備份到 `%TEMP%`，測試後還原並驗證雜湊；原版遊戲檔案保持唯讀。2026-10-27 安裝版首次截圖黑畫面，等待約一分鐘後主選單與歷史地圖列表正常顯示；持續黑畫面的阻礙未重現，但仍未載入自製地圖。下一步以備份／可還原的自製測試地圖驗證 editor export、遊戲載入與實際玩法。

## 2026-10-26 續作狀態與下一步

- AI 地圖工作室生成、預覽、套用已由實際 Ollama 與桌面驗證；水深案例另完成 Safe Save、關閉重開，Undo／Redo 在另一個未儲存 TEMP 執行中分開驗證。此前 live gate 有完整閉環證據；本次水深 desktop 用例尚未在同一地圖連續跑完 Undo／Redo→Safe Save→重載。這些都不等於地圖遊戲內可玩。
- Safe Save 的 TEMP 測試必須由 `--game <TEMP 根目錄> --map ENDL_005` 開啟，讓別名 catalog 從 TEMP 遊戲根目錄可見；直接 `--map <路徑>` 的測試會缺少 catalog。TEMP 測試仍可能有既存設計警告，須在確認後走正常 Safe Save，不可用「立即儲存」略過驗證。
- 第 3 階段已補 Safe Save 無效事件拒存、重載後編輯、root＋child＋direct／particle-linked Light family 平移／重載、事件刪除守衛及多池回滾；其他原生 family 變體與支援邊界仍待核對。下一步進第 5 階段真實 OpenGL 畫面、資源失敗／fallback、實體高 DPI 與多螢幕驗收。桌面目前有兩個同名編輯器視窗，待使用者選定目標；第 6 階段仍受安裝版黑畫面阻擋，需先取得可觀察遊戲畫面或進程堆疊證據，再驗地形、水面、物件、事件與存讀檔。

- 最新建置在獨立桌面視窗成功載入 TEMP `ENDL_005`；實際切換 2D Blended／Height／Collision 與 3D Textured，材質 atlas 畫面可見，Height 起伏與 Minimap 輪廓吻合。僅切換檢視，未編輯／儲存地圖；安裝版保持唯讀。此前「桌面有同名視窗、待選定目標」已由獨立啟動的新建置視窗避開。
