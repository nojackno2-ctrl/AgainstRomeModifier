# 羅馬帝國地圖編輯器使用者指南 (Map Editor User Guide)

## 1. 開始使用

### 1.1 執行環境與啟動方式

- **程式架構**：編輯器為 Rust 原生桌面程式（基於 egui / eframe），Windows x64 可攜版不依賴 .NET 或外部執行階段。解壓縮釋出套件後直接執行 `against-rome-editor.exe`。
- **開發者原始碼建置與執行**：
  在儲存庫根目錄透過 PowerShell 啟動：
  ```powershell
  powershell -NoProfile -ExecutionPolicy Bypass -File tools/run-rust-editor.ps1
  ```
  自動化測試指令：
  ```powershell
  cargo test --workspace --locked
  ```
- **命令列參數**：
  - `--game <路徑>`：指定遊戲安裝根目錄（例如 `C:\Program Files (x86)\Against Rome`）。
  - `--map <地圖代碼或路徑>`：開啟指定地圖（例如 `--map ENDL_005` 或完整路徑）。
  - `--validate-map`：執行唯讀地圖檢查，不開啟 GUI 介面、不寫入檔案；若存在阻擋儲存之重大錯誤結束碼為 2。若搭配 `--game` 且省略 `--map` 則批次檢查所有非戰役自製地圖。
  - `--lang zh` / `--lang en`：指定命令列輸出與編輯器介面預設語系。
  - `--smoke-test`：進行三次無頭渲染回歸檢查後正常退出。

### 1.2 遊戲目錄、權限與字元編碼合約

- **唯讀官方資產**：編輯器執行時依賴遊戲安裝目錄載入官方模型定義、貼圖、字型與部族資料（`alr.dat`、`apt.dat`、`objdef.dau`、`formdef.dau`、`SYSTEM/cl_alr.ini`、`SYSTEM/cl_apt.ini`、`SYSTEM/clengine.ini` 等）。
- **原版地圖防寫保護**：官方原始地圖（如戰役與原廠無盡地圖）一律標記為唯讀，編輯器嚴格禁止直接覆寫原版地圖；請使用「複製為自製地圖」功能建立副本後再進行修改。
- **檔案寫入權限**：若遊戲安裝於受系統保護目錄（如 `C:\Program Files (x86)`），儲存自製地圖時需具備對應資料夾寫入權限，或建議將工作副本置於一般使用者資料夾。
- **CP1251 編碼限制**：地圖名稱、任務簡報與事件文字在遊戲引擎底層均遵循 **CP1251** 編碼。輸入中文或不支援字元時欄位會發出警告提示；文字跳脫後的單一字面常數上限為 **100 位元組**，多行簡報會由編輯器自動拆分以避免溢位。

### 1.3 介面導航與 2D/3D 視角

- **頂部工具列與新手入門**：頂部按鈕均具備完整雙語 Tooltip，提供「新手入門 (Getting Started)」，清晰引導地圖初始化、地形雕刻、材質通行、物件部隊、劇本事件 5 大核心步驟。
- **底部狀態列即時讀數**：游標移動時即時顯示精確世界座標（X, Z，全圖範圍 0–16384）、圖塊座標（Tile X, Z，網格 0–255，每格 64 世界單位）、頂點原始高度（Height 0–255）與真實高度（World Y）、游標處地表材質名稱以及自然筆刷密度讀數。
- **2D 俯視畫布**：直觀顯示地勢高程、水域、碰撞阻擋、地表材質與物件圖示縮圖，支援滑鼠滾輪縮放（以游標為錨點）及中鍵／方向鍵平移。
- **3D 原生視角 (Viewport 3D)**：
  - 採用與遊戲一致之正交等角投影（俯角 30°），支援 1:1 真實比例尺渲染。
  - 讀取原生 `vertex.bmp` 烘焙光照、完工建築外觀、雙層合成樹木、陰影素材 (`shad.dat`) 及待機動畫。
  - 放置部隊自動依據 `formdef.dau` 展開陣形，士兵以所屬隊伍代表色著色，並依自訂朝向角度旋轉。
  - 提供遊戲光照即時預覽（讀取 `lightdef.dau` 與 d00–d09 覆蓋檔，依建築 frame 光源計算光暈）。
- **右下角小地圖 (Minimap)**：
  - 支援單擊或拖曳即時跳轉視角（2D 畫布與 3D 視角同步連動），金黃色線框顯示目前可見視窗範圍。
  - 支援選取物件瞄準環顯示、劇本相機點位與部隊生成點標記之可視化切換。
- **跨工作階段面板記憶 (Session Panel Memory)**：
  - 編輯器關閉或切換地圖時，自動將目前開啟的面板清單安全持久化儲存於 `%APPDATA%\AgainstRomeModifier\editor\editor-panels.json`，下次啟動時自動還原面板佈局，絕不污染遊戲目錄。

## 2. 新增地圖（精靈、地圖屬性）

### 2.1 新增對戰地圖精靈 (New Skirmish Map Wizard)

主選單提供四步驟精靈，協助設計者快速構建標準對戰地圖：

1. **步驟一：範本選擇**：
   - **平坦範本地圖 (Flat Template，推薦)**：以完整的原版無盡範本為基礎，自動整平地貌至安全水位高度並清除障礙，保留官方完整的 24 個 DATA 池、派系架構與安全參照。
   - **空白場景 (Blank Scene，實驗性)**：採用獨立乾淨架構，清除舊有無盡腳本與所有執行期資料池，改由獨立等待腳本驅動，需自行放置所有部隊、聚落與勝負條件（詳見 `docs/map-editor-blank-map-contract.md`）。
2. **步驟二：標題與任務簡報**：
   - 輸入地圖名稱、副標題與戰役簡報文字，支援自動拆分符合 CP1251 100 位元組限制之安全文字常數。
3. **步驟三：基地規模與規則設定**：
   - 設定玩家人數（2 至 8 人）、主勢力部族風格（日耳曼、羅馬、塞爾特、匈人）。
   - 勾選是否生成起始聚落、周邊森林與採石場，以及選擇進攻波次範本與勝負條件預設。
4. **步驟四：確認摘要並建立**：
   - 點擊「建立」後一次性生成全部配置，所有變更均為未存檔之記憶體草稿，並自動觸發「設計檢查 (Design Check)」，確認無誤後即可透過安全儲存寫入磁碟。

### 2.2 地圖屬性設定 (Map Properties)

- **基本中繼資料**：可隨時修改地圖標題、副標題與戰役任務簡報。
- **開局鏡頭 (Starting Camera)**：
  - 勾選啟用開局預設鏡頭位置，輸入世界座標 X/Z。
  - 提供「置中玩家主屋 (Center on player main house)」按鈕，一鍵自動抓取隊伍 0 主城座標並填入開局鏡頭。
- **重設平坦地形 (Reset Flat Terrain)**：
  - 可在既有地圖上將地形整平至水位 + 20 高度，重設碰撞與基礎材質，同時安全保留場景中的聚落、既有部隊與事件標記。

## 3. 地形與材質

### 3.1 高度工具 (Height Editing)

- **六種雕刻模式**：
  - **升高 (Raise, 快捷鍵 1)**：筆刷範圍內地形頂點高度上升。
  - **降低 (Lower, 快捷鍵 2)**：筆刷範圍內地形頂點高度下降。
  - **整平 (Flatten, 快捷鍵 3)**：平滑過渡至基準目標高度。點擊起點自動取樣，或在游標處按 **H 鍵** 取樣游標頂點高度。
  - **平滑 (Smooth, 快捷鍵 4)**：消除局部階梯落差與銳利噪點。
  - **粗糙 (Roughen, 快捷鍵 5)**：增加微幅起伏，營造自然粗糙岩面。
  - **水面／下挖 (Water, 快捷鍵 6)**：快速挖掘下陷窪地與湖泊河床。
- **強度與筆刷控制**：提供輕 (Gentle)、中 (Medium)、強 (Strong) 三種雕刻強度；按 **`[`** 與 **`]`** 鍵快速增減筆刷半徑（1 至 64 頂點）；內建 Bresenham 軌跡補點，快速拖曳不中斷。

### 3.2 通行區域 (Passability & Collision)

- **直接讀寫 `collision.bmp`**：
  - **設定阻擋 (Block, 快捷鍵 7)**：繪製不可通行區域，以半透明紅色覆蓋層呈現，阻止單位穿越。
  - **清除阻擋／通行 (Clear, 快捷鍵 8)**：擦除阻擋像素，恢復為可行走區域。
- **顯示切換**：在通行編輯模式下自動開啟紅色覆蓋層，切換至其他工具時自動隱藏，維持畫面清晰。

### 3.3 地表材質與圖塊印章 (Textures & Tile Stamps)

- **材質筆刷 (快捷鍵 9)**：圓形筆刷繪製基礎地表材質，系統自動遵循原版過渡圖層進行邊界混合。
- **材質吸管 (Eyedropper, 快捷鍵 I / 2D 右鍵)**：在 2D 畫布或 3D 視角游標處吸取地表材質或印章，自動選定調色盤並切換至材質工具，狀態列即時回報材質名稱。
- **土路繪製 (Dirt Path, PFAD)**：使用原版經典 `PFAD` 圖塊，拖曳筆刷即可自動銜接直路與邊界片（建議使用 3×3 以上筆刷以利完整拼接轉角）。
- **圖塊印章 (Tile Stamps)**：
  - **地區篩選 (Biome Filter)**：預設依地圖當前氣候（日耳曼 GER=L2、匈人 HUN=L3、不列顛 BRI=L4、羅馬/義大利 ITA=L5、喀爾巴阡 KAR=L13/15）嚴格篩選圖塊，防止混用不符氣候之素材；可勾選「顯示其他地區圖塊」解除限制。
  - **自動選路 (Auto-Pathing)**：開啟後連續拖曳筆畫，系統自動比對並選用直路、彎角、T 字路口、十字路口與端點片。

### 3.4 地貌與防禦工事工作室 (Landscape & Region Tools)

- **矩形懸崖岩壁 (Cliff Face)**：自動掃描 257×257 高程陡坡與坡向，選用原版真實岩壁圖塊（北坡 `Fels_AA_008`、東坡 `Fels_AA_004`、南坡 `Fels_AA_002`、西坡 `Fels_AA_006`），自動寫入 4×4 阻擋像素並生成坡腳碎石過渡。
- **矩形水系河流 (River Flow)**：規劃河道走勢，自動下挖至水面以下並保持 3 頂點平滑岸坡。
- **矩形植被散播 (Flora Scatter)**：依地形高程與生態圈規則自動散布適配當前氣候之樹木與植物。
- **水力與熱力矩形侵蝕 (Erosion)**：模擬天然降雨沖刷與熱風化作用，撫平生硬的人工雕刻稜角。
- **城牆與木柵折線 (Wall / Palisade)**：依據設定之航點沿線以 64 世界單位間距排列真實防禦工事物件（`Pal00`、`Pal01`、`Pal02` 等）。

### 3.5 自然景觀物件 (Nature Objects)

- **槽位架構**：直接讀寫地圖 `DATA/objects.dat`、`objdata.dat` 與 `position.dat` 之靜態槽位。
- **種植與移除**：支援樹木 (Trees)、草叢花卉 (Grass & Flowers)、灌木 (Bushes)、水生植物 (Reeds)、岩石 (Rocks) 等類別；提供稀疏 (Sparse)、一般 (Normal)、茂密 (Dense) 三種密度模式。
- **防護邊界**：全地圖世界物件數量嚴格控管於 **14,000 個** 上限以內，嚴格排除與保護腳本標記 (Skriptmark)。

## 4. 物件與聚落

### 4.1 放置物件：建築與部隊

- **完工建築 (Prebuilt Buildings)**：
  - 支援隊伍 0 至 8（隊伍 0 為玩家，隊伍 8 為中立）。
  - 儲存時自動匹配官方完工範本 (`Bau*`) 並寫入 `DATA/objects.dat`；若無對應範本則自動退回腳本生成（進入遊戲時為 0% 工地狀態），確保存檔安全不中斷。
- **人物與部隊 (Characters & Units)**：
  - 透過 `SCRIPT/ak_level.bci` 主程式開頭注入腳本 shim 實現動態生成。
  - 隊伍 0 至 7，支援人數 1 至 20 人，3D 視角中自動依照 `formdef.dau` 展開士兵陣列與旗幟。
- **持久目標標識 (Persistent Target ID)**：
  - 每個放置物件獲配唯一持久 ID，供劇本觸發器事件進行條件與動作的精準關聯。

### 4.2 物件操作與批次選取

- **同類型選取 (Select Type)**：選取物件後點擊「選取同類型」，全選地圖上所有同款物件。
- **反向選取 (Invert Selection)**：一鍵反向選取全地圖物件（包含文字搜尋隱藏之項目）。
- **同隊伍選取 (Select Same Teams)**：擴展選取至所選隊伍之全部物件。
- **座標複製 (Copy X/Z, 快捷鍵 K)**：一鍵將游標處精確世界座標複製至剪貼簿。
- **視角聚焦 (Frame Selection, 快捷鍵 F)**：立即將 2D 畫布或 3D 鏡頭置中對齊目前選取之物件或生成點。
- **微調移動 (Nudge, `Ctrl+方向鍵` / `Ctrl+Shift+方向鍵`)**：
  - `Ctrl + ArrowLeft` / `Ctrl + ArrowRight` / `Ctrl + ArrowUp` / `Ctrl + ArrowDown`：以 256 世界單位步長微調物件座標。
  - `Ctrl + Shift + ArrowLeft` / `Ctrl + Shift + ArrowRight` / `Ctrl + Shift + ArrowUp` / `Ctrl + Shift + ArrowDown`：以 64 世界單位步長進行精細微調。
- **物件複製與刪除**：按 **`Ctrl + D`** 原地複製選取物件（X/Z 自動偏移 256）；按 **`Delete`** 刪除選取物件（支援放置物件、生成點與場景標記；自然物件請使用自然筆刷移除）。
- **中心對稱複製 (Copy Opposite)**：以 (8192, 8192) 地圖中心點鏡射複製整批選取群組，自動計算對稱座標與目標高度。
- **原生群組操作 (Bound Groups)**：選取場景中附屬物件、光源與營地綁定之獨立群組時，支援整組平移與複製，自動為所有子項配置全新獨立身份。

### 4.3 一鍵生成對戰基地 (Settlement Generator)

位於「配置 (Layouts)」 選單中的基地自動規劃工具：

- **玩家規模與對稱模式**：支援 2 至 8 位玩家。2 位玩家自動採用中心對稱 (`CentralSymmetry`)，3 至 8 位玩家採用旋轉對稱 (`RotationalSymmetry`)。
- **四大部族支援**：日耳曼（主屋 `BauGerHau00_Haupthaus`）、羅馬、塞爾特、匈人（以 `SCHLA` 屠宰場代替農場；中立野豬 `FigTieEbe00`）。
- **智慧平衡評估**：自動評估地勢平坦度、避開水面與碰撞阻擋網格，對稱生成主城、建築佔地、木材林區與採石場。
- **2D 畫布即時預覽**：點擊「套用」前可勾選「在 2D 畫布預覽配置」，畫布即時顯示各勢力雙環錨點、建築佔地線框與資源點位，未提交前絕不改動地圖。
- **各勢力資源明細表與聚焦**：詳細列出各基地之座標、建築數、木材、石材與食物資源數量，提供「聚焦 (Focus)」按鈕一鍵置中視角。
- **隨機種子重抽快捷鍵 (`Ctrl+R` / `Alt+R`)**：支援快捷鍵或點擊「🎲 使用新種子碼重新產生 (Ctrl+R / Alt+R)」按鈕，快速隨機抽換種子碼並即時重算平衡基地。
- **自訂配置範本 (`.arm-layout.json`)**：支援將選取之聚落配置或森林區域匯出為 JSON 範本，以便於不同地圖間套用。

## 5. 劇本與事件

### 5.1 規格合約與限制

- **事件總數上限**：全地圖最多 **256 個** 事件。
- **動作上限**：每個事件支援 **1 至 32 個** 動作。
- **條件上限**：每個事件支援 **0 至 32 個** 條件（全部條件皆滿足時才觸發，AND 邏輯；無條件時為純定時事件）。
- **計時設定**：延遲時間範圍為 0 至 86,400 秒；若勾選「週期重複 (Repeat)」，重複間隔至少需為 1 秒。
- **條件觸發時間合約**：**有條件之事件，其延遲時間（Delay）是自任務開局起算；當設定的所有條件均成立、且任務已進行時間達到延遲時間時，事件才會正式觸發**。

### 5.2 條件類型 (Conditions)

條件需綁定已放置物件或部隊之持久 ID：

1. **物件存在 (`ObjectExists`)**：偵測目標單位或建築實體是否存活於場景中（含尚未消失之殘骸）。
2. **物件死亡或移除 (`ObjectDeadOrRemoved`)**：目標必須曾被腳本輪詢確認存在，之後死亡或被清除時條件才成立。
3. **物件位於矩形區域 (`ObjectInArea`)**：偵測目標中心世界座標是否進入指定矩形閉區間（支援「在地圖上框選 (Draw on map)」直接設定座標）。

### 5.3 動作類型 (Actions)

動作依清單由上而下順序執行：

1. **顯示訊息 (`Message`)**：呼叫 `s_showTextBox` 彈出對話框（文字上限 1,000 位元組 CP1251）。
2. **改變外交 (`Diplomacy`)**：呼叫 `s_setTeamHostile` 設定指定兩隊伍間為敵對或和平。
3. **生成部隊 (`SpawnUnit`)**：於指定世界座標生成指定隊伍與人數之部隊。
4. **勝利 (`Victory`) / 失敗 (`Defeat`)**：結束任務並判定勝負。**合約限制：勝負動作必須為單次事件（非重複）的最後一個動作**。

### 5.4 劇本設計輔助功能

- **進攻波次產生器 (Attack Wave Generator)**：設定敵方隊伍、兵種別名、波數、首波時間、間隔秒數、數量遞增與生成／集結目的地；提供一鍵「讓波次進攻玩家主屋」，自動建立敵對外交事件。
- **勝負條件預設 (Objective Presets)**：一鍵建立「新增存活勝利 (Add survival victory)」、「玩家主屋摧毀即失敗 (Player main house destroyed: Defeat)」、「敵方主屋摧毀即勝利 (Enemy main house destroyed: Victory)」等常用邏輯。
- **視覺化事件節點圖 (Visual Event Graph)**：以雙緩衝節點畫布呈現事件流程與邏輯連接，草稿驗證通過後原子替換地圖事件，支援單步 Undo。
- **批次啟用／停用事件**：事件清單頂部提供「啟用全部 (Enable all)」／「啟用篩選 (Enable filtered)」與「停用全部 (Disable all)」／「停用篩選 (Disable filtered)」按鈕，便於除錯測試，支援一次性復原。
- **劇本範本匯入與匯出**：支援將事件匯出為 `.arm-events.json`，或將部隊生成點匯出為 `.arm-spawns.json`，匯入時提供隊伍重新對應功能。

### 5.5 多 AI 協同製圖流程 (Multi-AI Planner, Ollama)

支援透過本機 Ollama 服務分工規劃地圖：

- **三大角色職責**：
  - **地形專家 (Terrain Specialist)**：規劃山丘、山脈、山谷、高原、山脊與通行阻擋，掌管基礎地表高度。
  - **水系專家 (Water Specialist)**：規劃湖泊與河流走向。
  - **材質專家 (Materials Specialist)**：規劃地表材質覆蓋，掌管基礎材質。
- **特徵配額**：各角色上限 8 個特徵，全圖總計最多 24 個特徵。
- **推論流程**：依序發送請求（預設模型 `laguna-xs-2.1:latest`），生成後在 AI 企劃面板預覽示意圖，手動點擊「套用 AI 企劃至地形 (Apply Plan to Map Terrain)」後即時寫入編輯工作區，確認滿意後再執行安全儲存。

## 6. 檢查與分析

### 6.1 地圖設計檢查 (Design Check, 快捷鍵 F5)

設計檢查視窗可隨時按 **F5** 觸發，對地圖進行全域深度體檢：

- **規則檢查項目**：
  - 放置物件座標越界、部隊生成限制、建築工地回退問題。
  - 事件條件與動作有效性、波次缺少目的地 (`wave-no-destination`)、波次缺少敵對設定 (`wave-not-hostile`)。
  - 官方 24 個必要 DATA 檔案完整性檢查（缺檔時提示修復建議）。
  - DATA 資料池關聯：主要／次要／第三位置索引、光源 parent 關聯、直接光源與物件關聯驗證。
- **問題清單互動**：
  - 「搜尋問題 (Search issues)」依問題代碼與中英文說明篩選，不區分英文字母大小寫；「清除搜尋 (Clear search)」還原搜尋結果，層級篩選仍保留。
  - 清單頂部提供層級篩選：中文顯示 `錯誤 (N)`／`警告 (N)`，英文顯示 `Errors (N)`／`Warnings (N)`；N 為各層級問題數量。
  - 選取問題可閱讀完整診斷；雙擊或點擊「前往 (Go to)」按鈕，視角立即置中對準該物件或座標點。
  - 檢查目前記憶體中的候選狀態；結果不會替未儲存問題逐項加上特殊標記。
  - 提供「儲存後自動重新檢查 (Auto re-run after save)」選項。
- **匯出報告 (Export report)**：
  - 一鍵將報告輸出為 Markdown 檔案。
  - **安全路徑合約**：**報告預設儲存於外部安全目錄（如使用者 Documents），嚴格禁止寫入遊戲目錄或 `MAPS` 目錄中以維持遊戲純淨**。

### 6.2 通行與連通性診斷 (Navigation & Connectivity)

- **路徑估算**：在地圖上點選起點與終點，即時計算連通路線。支援「交換起終點 / Swap endpoints」與「清除診斷覆蓋 / Clear diagnostics」。
- **建築障礙模式**：
  - **APT Footprint 模式（真實數據）**：讀取原版 `objdef.dau` 與 APT 建築佔地網格，以真實佔地格阻擋進行計算；無法解析之建築退回近似邊距。
  - **近似邊距模式 (Approximate 384/64)**：採用固定範圍近似（主城 384、一般建築 64 世界單位）。
  - **注意**：兩種模式僅為診斷尋路估算，絕不修改底層 `collision.bmp` 檔案。

### 6.3 地圖平衡摘要 (Map Balance Summary)

- 唯讀摘要視窗：列出隊伍 0 至 7 之已放置建築數、腳本生成單位總數、敵方波次行軍時間表、重複事件間隔以及「條件觸發兵力」清單；若缺乏勝負條件會顯示醒目警告。

### 6.4 資源預算與效能分析器 (Budget Profiler)

- 分析地圖之世界物件槽位總量、光源密集度、預估繪製呼叫 (Draw Calls) 與尋路瓶頸，提供資源消耗評等與最佳化建議。

## 7. 存檔與復原

### 7.1 安全儲存機制 (Safe Save, 快捷鍵 Ctrl+S)

- **單一交易保證**：儲存時將地形高程、通行圖、材質、放置物件、DATA 關聯池、天候設定與劇本事件一次性原子寫入，避免檔案不一致。
- **存檔阻擋防護 (Cannot save yet)**：
  - 若設計檢查存在嚴重錯誤、資料池格式損壞或面板存在未套用草稿，編輯器會拒絕儲存並彈出清單，清楚列出阻擋原因與前往修正按鈕。
- **原版防寫阻擋**：開啟原廠地圖時強制防寫，按 Ctrl+S 提示需另存或複製為自製地圖。

### 7.2 跨子系統統一復原日誌 (Unified Undo/Redo)

- **快捷鍵**：按 **`Ctrl + Z`** 執行復原；按 **`Ctrl + Y`** 或 **`Ctrl + Shift + Z`** 執行重做。
- **全域操作涵蓋**：地形雕刻筆畫、通行阻擋塗抹、材質圖塊印章、放置物件新增／移動／複製／刪除、一鍵聚落生成、事件節點修改等，均納入統一 Undo Journal。
- **原子交易**：聚落生成、多選物件移動、中心對稱複製等複合操作，在復原時均作為單一步驟一次撤銷。
- **基準點重設**：成功執行安全儲存後，目前編輯狀態自動設為全新歷史基準，並清除先前的復原歷史；若儲存失敗則完整保留所有編輯內容與復原歷史供修復。
- **還原地表 (Reset Terrain)**：一鍵放棄所有未存檔之地形修改，還原至開圖時之地貌基準。

### 7.3 工具箱維護與備份 (Toolbox)

- 提供存檔與地圖備份掃描、選取存檔驗證、地圖修復以及安全還原工具。
- 「全部還原 (Stats+Compat+Language)」預設勾選「保留自製地圖」，防止誤刪設計者辛苦創作之自製作品。

## 8. 打包與分享

### 8.1 模組匯出器 (Mod Exporter)

- **標準化打包**：遵循 Against Rome Manifest 1.1 規格，將自製地圖之全部必要資產與中繼資料封裝為 ZIP 壓縮包。
- **安全匯出路徑**：**預設匯出目錄為外部使用者資料夾（例如 Documents），嚴格禁止直接輸出至遊戲 `MAPS` 資料夾或地圖目錄內部**。

### 8.2 地圖版本比對引擎 (Map Diff Engine)

- **8 大圖層深度比對**：
  1. 高程圖 (Heightmap)
  2. 碰撞阻擋 (Collision)
  3. 地表材質 (Textures)
  4. 放置物件 (Objects)
  5. 劇本事件 (Scenario events)
  6. 物件別名與人數 (Object alias/unit count)
  7. 劇本生成點 (Scenario spawns)
  8. 劇本資料槽位 (Scenario data slots)
- **比對來源**：支援比對記憶體當前工作區 vs 磁碟基準地圖。
- **狀態判定**：明確顯示 ✔ 相同 (Identical)、⚠ 存在差異 (Differences) 或 ✖ 無法比對 (Unavailable)。

### 8.3 配置與劇本資產共享

- **聚落範本**：`.arm-layout.json`（可匯出／匯入建築配置與森林地景）。
- **生成點範本**：`.arm-spawns.json`（可匯出／匯入獨立部隊生成點）。
- **劇本事件範本**：`.arm-events.json`（可匯出／匯入事件觸發邏輯，支援隊伍重組對應）。

### 9.1 其他輸入流程

復原由 `app.rs` 的更新迴圈直接處理，滑鼠與 2D 懸停方向鍵由視圖互動流程處理，不屬於上述兩個映射函式。

- `Ctrl + Z`：復原上一步操作 (Undo)；全域（非文字輸入，未受阻擋對話框鎖定）。
- `Ctrl + Y` / `Ctrl + Shift + Z`：重做下一步操作 (Redo)；全域（非文字輸入，未受阻擋對話框鎖定）。
- `方向鍵` (2D 懸停)：2D 畫布微調平移（步長 64 像素）；游標懸停於 2D 畫布且無修飾鍵時生效。
- `滑鼠中鍵拖曳`：平移 2D 畫布或 3D 鏡頭 (Pan)；`Alt + 滑鼠左鍵拖曳` 僅於 3D 視角提供相同平移操作。
- `滑鼠右鍵拖曳`：3D 鏡頭軌道旋轉 (Orbit)；僅於 3D 視角生效，圍繞目標點旋轉視角。
- `滑鼠滾輪`：平滑縮放視角 (Zoom)；2D 以游標為錨點縮放；3D 縮放攝影機焦距。
- `滑鼠左鍵單擊`：物件拾取與選取 (Pick & Select)；單擊選取物件；不超過 4 像素閾值不觸發位移。
- `滑鼠左鍵拖曳 (>4px)`：繪製地形/材質筆刷；或拖曳移動選取物件/標記；筆刷模式下繪製筆畫；選取模式下移動對齊格心。

## 10. 已知限制與待驗證項目

> **驗證範圍**：自動化測試涵蓋多項編輯流程與資料結構轉換，不代表所有功能均已完成端到端驗收；自製地圖在遊戲原生引擎（Against Rome）內的實際渲染效果、尋路連通性與開局行為，仍需進行人工實機確認。

人工驗收標準與步驟，請務必參閱：[遊戲內驗收清單 (docs/map-editor-ingame-checklist.md)](map-editor-ingame-checklist.md)。

### 10.2 引擎限制與現行未實作項目

1. **3D 原生視角預覽限制**：
   - 3D 視角中未模擬動態雲影、時段地形陰影與局部光源即時閃爍；建築光照係以錨點單點取樣，地形起伏倍率不改變光源在遊戲原生引擎中的真實照明半徑。
   - 旋轉 225° 以上與騎兵朝向之換算尚未於遊戲內完整實測。
   - 地形目前不會遮擋其後方的物件；草地等多重散布類物件在 3D 視圖中僅渲染單一圖像。
2. **環境音效區域原生匯出**：
   - 目前編輯器中之環境音效區域編輯屬於音景原型，原生音區二進位資料匯出尚未接通，音區草稿不會寫入遊戲讀取的二進位檔。
3. **開局多航點時間軸運鏡**：
   - 目前僅支援開局單點攝影機座標設定；多航點時間軸運鏡為獨立功能，尚未完成遊戲內驗收。
4. **戰役波次與行為姿態限制**：
   - 目前 AI 戰役波次僅支援定時部隊生成。巡邏路線、指定攻擊目標物件、部隊相對延遲以及勢力戰術姿態等設定，尚未由底層 ScenarioEvent ABI 支援，企劃編譯器會明確報錯拒絕。未套用至地圖之草稿會阻擋安全儲存。
