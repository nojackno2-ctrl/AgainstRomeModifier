# 遊戲內驗收清單：劇本設計輔助功能

2026-10-25，本地 AI 起草、Claude 審查修正。供人工在遊戲內確認 2026-10-24～25 新增的劇本設計功能；這些功能目前只通過自動化測試。

## 前置作業
- [ ] 只使用自製測試地圖（例如 `MAPS\ENDL_005`），測試前先完整備份到 `%TEMP%`
- [ ] 確認備份完成；不要修改任何原版遊戲地圖

## 檢查 A：進攻波次產生器
- [ ] 在劇本面板的「進攻波次產生器 (Attack wave generator)」設定：敵方隊伍=1、單位別名、波數=3、首波秒數=60、間隔秒數=60、基本數量、每波增加，設定生成 X/Z，目的地按「玩家主屋 (Player base)」
- [ ] 執行「設計檢查 (Design Check)」，確認沒有 `wave-not-hostile` 或 `wave-no-destination` 警告
- [ ] 以「Safe Save」儲存地圖
- [ ] 進入遊戲，確認波次約在 1:00、2:00、3:00 出現
- [ ] 確認每波敵軍顯示紅色（敵對）血條、朝玩家主屋移動並發動攻擊
- [ ] 記錄：通過／失敗、觀察時間、截圖路徑

## 檢查 B：勝負條件預設
- [ ] 在「勝負條件預設 (Objective presets)」新增「存活 N 秒勝利」，N=120
- [ ] 新增「玩家主屋被摧毀即失敗」
- [ ] Safe Save 後進入遊戲，確認約 2:00 出現勝利
- [ ] 重新開局，讓玩家主屋被摧毀，確認出現失敗
- [ ] 記錄：通過／失敗、觀察時間、截圖路徑

## 檢查 C：區域條件
- [ ] 建立一個事件，條件用「在地圖上框選 (Draw on map)」畫出矩形區域，動作設為顯示訊息
- [ ] Safe Save 後進入遊戲，單位進入區域前確認訊息「沒有」出現
- [ ] 將單位移入區域，確認訊息出現
- [ ] 記錄：通過／失敗、觀察時間、截圖路徑

## 檢查 D：存檔與重新開啟
- [ ] 完成編輯後 Safe Save，關閉編輯器再重新開啟地圖，確認所有設定仍在
- [ ] 進入遊戲，確認地圖能正常開局
- [ ] 記錄：通過／失敗、觀察時間、截圖路徑

## 收尾
- [ ] 測試結束後，用 `%TEMP%` 的備份還原測試地圖
