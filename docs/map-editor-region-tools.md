# 區域與框選工具

工具列「區域工具…」可輸入圖格座標（目前地圖為0..63，實際上限顯示於對話框）。每行使用 `X,Y`：

- 矩形填色：兩個對角；包含邊界格，使用目前調色盤材質。
- 同材質連通區填色：一個起點；四方向搜尋，按材質分類而非隨機圖塊變體判定，未分類圖塊按原生名稱判定。
- 土路折線：至少兩點；每段補齊連通格，寬度以格計，使用原版PFAD土路與接縫。偶數寬度朝座標正方向多一格。
- 矩形選取物件：兩個對角；按放置物件錨點選取，選取後可批次隊伍／方向、複製或刪除。

工具列「框選」讓2D及3D檢視左鍵拖曳矩形，放開後選取放置物件；Escape或切換工具取消。框選按錨點而非整個部隊陣型／建築範圍判定。

地表操作先集中修改角點，再一次烘焙原版材質；原版素材無法表示的接縫使整個區域操作拒絕，狀態列指出第一個失敗圖格。成功操作合為一次Undo，儲存前不寫地圖檔。對話框取消不修改內容；沒有PFAD素材時不能生成土路。

驗證：純模組涵蓋反向矩形、四向填色、連通斜路、邊界寬度、烘焙拒絕、redo及pending保留；宿主涵蓋對話框取消、框選事件、一次undo/redo與save/reload。真實TEMP副本示範驗收以折線34,33→44,33→44,37、寬度3走完整儲存／重開與GL輸出；遊戲內效果另待驗收。
