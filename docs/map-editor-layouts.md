# 可重複套用的聚落與森林配置

工具列「配置」提供三項操作：

- 保存選取的聚落／物件：在放置物件分頁多選建築、部隊等，或先用框選，保存為 `.arm-layout.json`。以選取物件最小X／Z為原點。
- 保存森林區域：輸入矩形兩個對角圖格；保存範圍中的可移除、未連結自然物件與待存新增物件，排除已移除物件。以矩形左上角為原點。
- 載入並套用配置：選擇JSON，輸入目標錨點圖格與旋轉角度；聚落／物件可指定新隊伍。貼合目前地形，保留原來相對地形的高度偏移。

配置只含名稱、相對座標、角度、隊伍及數量；不保存遊戲二進位範本、runtime UID、事件或原物件GUID。物件類型由目前遊戲目錄的catalog解析，自然物件使用目前圖或已載入的官方圖安全範本。新放置物件獲得新GUID；原有物件與事件目標不變。

所有類型與旋轉後位置先驗證，再整批加入。缺類型、位置越界、無效隊伍／人數或JSON版本不支援時拒絕整批。成功套用一次Undo／Redo；按「儲存」前不寫地圖檔，取消套用對話框不修改地圖。檔案最多2MB，版本1最多4096個物件。

聚落建築先使用官方完工模板，再使用目前圖內安全、未連結的同類型模板；兩者缺失時仍為工地回退，地圖檢查會列出警告。套用不複製腳本事件、資源庫存、聚落AI設定或與其他物件的原生連結；遊戲內可用性另行验收。

驗證涵蓋JSON往返、90度旋轉、貼地高度、重複套用新ID、未知類型與越界整批拒絕、一次undo、取消、原事件目標保留、save／fresh reload／重存bytes。真實TEMP示範另輸出forest與settlement JSON，逐株native位置／旋轉、新建築slot／UID／team及完整native重新載入也納入驗證。
